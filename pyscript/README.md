# F1 Watchability - Inference Engine (Pyscript)

This folder contains the Home Assistant logic to calculate watchability scores.

## Files

-   **`f1_watchability.py`**: The main script.
-   **`weights.json`**: The model configuration (generated by `/calibration`).
-   **`f1_history.json`**: Stores the last 5 race results (auto-generated if missing).

## Installation

1.  **Prerequisites**:
    -   Ensure [HACS Pyscript](https://github.com/custom-components/pyscript) is installed in Home Assistant.
    -   **Important**: You must install `fastf1` in your Home Assistant Python environment.
        -   *Option A (Docker)*: Add `fastf1` to your `requirements.txt` or install manually in the container.
        -   *Option B (Pyscript)*: Pyscript might attempt to install dependencies if listed in a `requirements.txt` in this folder, but `fastf1` can be heavy. Use with caution.

2.  **Deploy**:
    -   Copy the contents of this folder (`f1_watchability.py`, `weights.json`, `f1_history.json`) to your Home Assistant configuration directory: `config/pyscript/`.

3.  **Restart**:
    -   Reload Pyscript or restart Home Assistant.

## Usage

-   The script automatically runs **5 minutes** after `sensor.f1_session_status` changes to `Finished`.
-   You can manually trigger a check by calling the service: `pyscript.f1_watchability_check`.

## Configuration

-   **`weights.json`**: Update this file if you re-run the calibration script.
